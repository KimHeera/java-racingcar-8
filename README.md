## 💻 기능 목록

---
### 입력
- [ ] 사용자로부터 이름을 입력 받는다.
- [ ] 쉼표가 있다면 분리한다. (다른 특수문자는 허용하지 않는다)
- [ ] 입력받은 이름이 '5자 이하'인지 확인한다. 아니라면 IllegalArgumentException 발생 후 종료
- [ ] 사용자로부터 이동을 시도할 횟수를 입력 받고, 양수인지 확인한다. (음수라면 IllegalArgumentException 발생 후 종료)


### 게임
- [ ] racing car 객체 생성 & 초기화 (이름, 전진 횟수, 무작위 값 변수 필요)
- [ ] 0 - 9 사이의 무작위 값을 구한 후, 4 이상이라면 전진 +1
- [ ] 한 번의 이동 시도마다 결과값을 출력

### 결과
- [ ] 가장 많이 이동한 우승자를 구한다.
- [ ] 공동 우승자가 있다면 쉼표로 구분하여 함께 출력
